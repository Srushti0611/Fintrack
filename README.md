# FinTrack – Personal Finance Tracker

A web-based personal finance management application built using **Python, Django and MySQL**. FinTrack helps users manage their income, expenses, budgets and savings through a simple and user-friendly interface.

## 🚀 Features

- User registration and login
- Add, edit and delete transactions
- Manage income and expenses
- Organize transactions by categories
- Set and manage budgets
- Track savings
- Dashboard for financial overview
- Export transaction data to CSV
- Responsive user interface

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/Srushti0611/FinTrack.git
```

2. Open the project folder:

```bash
cd FinTrack
```

3. Create and activate a virtual environment:

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

4. Install dependencies:

```bash
pip install -r requirements.txt
```

5. Configure your MySQL database in Django's `settings.py` using your local database credentials.

6. Apply database migrations:

```bash
python manage.py makemigrations
python manage.py migrate
```

7. Start the development server:

```bash
python manage.py runserver
```

8. Open the application:

```text
http://127.0.0.1:8000/
```

## 🎯 Project Objective

The objective of FinTrack is to provide a convenient way for users to record and monitor their financial activities, manage budgets and understand their spending habits.
